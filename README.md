# Desafio DIO - Gerenciamento de Instâncias EC2 na AWS

## Descrição
Este repositório documenta a prática de criação, configuração e gerenciamento de instâncias EC2 na AWS, realizada como parte do desafio da DIO.  
O objetivo é demonstrar o entendimento dos principais conceitos de computação em nuvem e operação de servidores virtuais.
